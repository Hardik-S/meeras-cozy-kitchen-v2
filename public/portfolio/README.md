# Portfolio Photo Replacement Guide

Use this folder for Meera's real launch photos.

## Photo Rules

- Use Meera's own photos, not stock photos, before promoting the site.
- Ask permission before posting customer cakes publicly.
- Prefer daylight photos with the full cake visible.
- Include one clean cake photo, one slice/detail photo, and one packaging/pickup photo when possible.
- Do not add fake testimonials or imply a placeholder photo is a completed customer order.

## Suggested Filenames

- `six-inch-floral-cake.jpg`
- `birthday-cupcakes.jpg`
- `simple-celebration-cake.jpg`
- `dessert-box-sample.jpg`
